# NJU GPA Excel 计算器

这是一个完全在本机运行的成绩 Excel 计算工具，不需要安装浏览器扩展。

> 本项目是非官方辅助工具，与南京大学官方无隶属关系；计算结果仅供个人参考。

## 使用方法

1. 在南京大学“我的成绩”页面点击“导出”。
2. 双击 `打开GPA计算器.html`。
3. 选择或拖入刚刚导出的 Excel 文件。
4. 使用“课程性质”按钮整类选择平台、通修、通识等课程，GPA 和已选学分会自动更新。

## 数据规则

- 优先匹配 Excel 中明确标为“课程性质”的列，因此分类与导出文件保持一致。
- 支持“课程名 / 课程名称”“总成绩 / 总评成绩 / 成绩”等常见表头。
- “通过、合格、不通过、不合格”等非数值成绩会显示，但不参与 GPA。
- 等级制成绩按“优秀 95、良好 85、中等 75、及格 65、不及格 0”换算。也就是说，85 只会来自 Excel 中明确写着“良好”的成绩，绝不会把“通过”改成 85。
- 计算方式：`Σ（成绩 × 学分）÷ Σ学分 ÷ 20`。

## 隐私

Excel 文件仅由本机浏览器读取。工具没有服务器地址，不上传、不保存成绩数据；关闭页面后数据即从内存释放。

请保留文件夹内的 `app.js`、`app.css` 和 `xlsx.full.min.js`，不要只单独移动 HTML 文件。

## 在线部署

仓库已经包含 GitHub Pages 所需的 `index.html` 和 `.nojekyll`。启用 Pages 后，使用者可以直接在浏览器中打开网页；Excel 仍只在使用者自己的浏览器内解析，不会上传到服务器。

## 兼容格式

支持 `.xlsx`、`.xls`、`.xlsb` 和 `.csv`。工具会在工作簿前 40 行中自动查找成绩表头，并选择识别到课程最多的工作表。
